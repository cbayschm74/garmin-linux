Checked 2026-10-03 against the [read-only installed map inventory](map-inventory.md). This assessment records documented routes and what can be inferred from files and the user's account history. It does not claim that Garmin Express has offered any particular update to either connected device; Express was not run and no map was downloaded or changed.

## User-provided context

- The user has an OpenMTBMap.org account and primarily uses its maps. Account access or current membership status was not tested; no credentials are stored by this project.
- The user reports buying one Garmin Chile topographical map for the Edge 1000. The Edge SD card contains `D4172020A.img`, whose embedded title is **Topo Chile Deluxe 2014.20**. This is the likely purchase, but the file alone does not prove the transaction or reveal its account entitlement.
- The user did not report buying the other Garmin map files. Their presence does not establish whether each was preloaded, included with the device, later installed, or transferable.

Garmin's [purchased-map guidance](https://support.garmin.com/en-US/?faq=I4EBCSF7N73Rs4wwnkSoN8) distinguishes preloaded maps, preprogrammed cards, and downloadable purchases. A purchased IMG and accompanying `.gma`/`.unl` files are not a license or update catalog that this Linux app can safely interpret. The documented [Edge purchased-map flow](https://support.garmin.com/en-AU/?faq=g9PbvR7queA7AoYCEZF5v8) requires Garmin Express and the purchasing account. Garmin [provides Express for Windows and Mac, not Linux](https://support.garmin.com/en-AU/?faq=9MuiEv9c2y2wgcXvzEVEe8). No documented personal Linux entitlement/download interface was established for Garmin maps. The app can inventory installed versions and guide the user to Express; it should not promise to fetch Garmin map payloads.

## OpenMTBMap path for this project

The [OpenMTBMap IMG download instructions](https://openmtbmap.org/download/gmapsupp/) explicitly cover Linux, renaming an unpacked `gmapsupp.img` for newer devices, placing it in the SD card's `Garmin` directory where available, and keeping contour lines separate. They identify the **Edge 1000** among devices needing **Non Unicode** OpenMTBMap variants. The installed China filenames include `NU_Eng`, consistent with that choice. The fēnix map should use a format actually accepted by that watch; its existing IMG proves that a similar file is present, not that every current download variant will work. The [Windows/Linux desktop downloads](https://openmtbmap.org/download/odbl/) are another source for assembling selected regions, while the ready-to-copy member IMG archive is the simpler first route.

### Local China downloads inspected on 2026-10-03

- `/home/cbayschm/Downloads/mtbchina.exe` (about 1.4 GB) is a Windows PE/NSIS installer **and** a readable archive. `7z l -slt` lists 125 IMG entries, including numbered map tiles and desktop mapset files, plus `information for Linux_or_QlandkarteGT_users.txt`. The embedded instructions describe using the cross-platform Java `mkgmap` tool to create a device `gmapsupp.img`. There is no ready `gmapsupp.img` inside the archive and no Linux `.sh` script inside it. [OpenMTBMap explicitly documents extracting its `.exe` on Linux with 7-Zip](https://openmtbmap.org/download/odbl/) and links an external Linux script. The Windows installer itself need not be executed.
- `/home/cbayschm/Downloads/china_contours.7z` (about 6.1 GB) is a standard 7-Zip archive with 815 IMG entries, mainly numbered contour tiles and desktop mapset support files. It contains no ready `gmapsupp.img` and no Linux installer. Its version file names the 20 m contour data dated 2021-07-11; OpenMTBMap says contour data changes less often and is a separate optional download.
- These **desktop/tile packages** must be assembled into a device-ready image with the correct map family/layout and size limit before transfer, or the user can download the separate [ready-to-copy member IMG package](https://openmtbmap.org/download/gmapsupp/). Simply copying `mtbchina.exe`, the `.7z`, or a numbered tile IMG into `Garmin/` is not the documented device install path. Neither archive was extracted fully or executed during this inspection; no Garmin volume was mounted or changed.

A subsequent local trial assembled a regional China IMG from 11 map tiles and 22 contour tiles for each device layout. See [build details and verification](openmtbmap-china-build.md). The archives are still not fully extracted, the installer was not executed, and no device map was changed.

For a future Linux updater, support a **user-downloaded local archive** first. The inspector must distinguish ready-to-copy `gmapsupp.img` archives from NSIS/7-Zip tile packages that still need assembly. The app can verify the publisher's MD5 plus its own SHA-256 copy check, inspect IMG metadata and size, show target volume and filename, preserve the old map privately, and write only after explicit selection and a full device-specific backup/recovery design. Never overwrite Garmin-branded maps or license sidecars. Do not store OpenMTBMap credentials or attempt an undocumented account login API. Large images and the watch's unreliable USB connector make a test-and-recovery plan necessary before any live map transfer.

QMapShack can [load IMG files as desktop basemaps](https://github.com/Maproom/qmapshack/wiki/DocInstallMapDem), so it is a good planning companion. That is distinct from installing a map on a Garmin device. We have not verified a QMapShack IMG-to-device installation workflow for these two models. This project will own the guarded transfer of user-downloaded OpenMTBMap maps after it passes the map-specific backup and recovery gate; QMapShack will remain the route editor/map viewer. Viking's documented map layers are mainly online or cached raster tiles, not OpenMTBMap Garmin IMG. See [route editor comparison](route-editors.md).

## Practical Garmin check

When a Windows or Mac computer is available, connect each device to [Garmin Express](https://support.garmin.com/en-AU/?faq=9MuiEv9c2y2wgcXvzEVEe8) with its normal USB cable. Inspect **Map Details / Manage Maps**, **View Details**, and **Tools & Content → Purchased** while signed into the Garmin account used for the Chile purchase. Record the map titles and any offered updates or purchase options; do not install or delete anything merely to perform the check. This is the remaining account-specific evidence needed to say what Garmin will actually deliver to these units.

The fēnix phone sync and Edge Wi-Fi “no updates available” result in the [firmware assessment](firmware-feasibility.md) checked main software only. They do not settle map availability.
